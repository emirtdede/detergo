These files are the previous Dev Cleaner identity. They are kept for history and
provenance only. **Nothing in this directory may be referenced by a shipping
surface** (application, installer, README, website, GitHub).

The current canonical identity lives in `assets/brand/` and is described in
`docs/brand/BRAND_GUIDELINES.md`. The brand scan (`npm run check:brand`) treats
this directory as an explicit exception.
